## 2. 训练入口

学生路径：

**学习工具 → 高一化学** → 选择一级专项 → 二级分类「开始训练」→ 设置参数 → 答题 → 提交 → 结果；或从首页/专项页进入「训练历史」。

前端路由：

- `/chemistry`
- `/chemistry/:code`
- `/chemistry/:code/train`
- `/chemistry/train/session/:id`
- `/chemistry/train/result/:id`
- `/chemistry/train/history`

---

## 3. 支持题型

| 题型 | 代码 | 判题 |
|------|------|------|
| 单选题 | `single` | 选项键精确匹配 |
| 判断题 | `judge` | 正确/错误（及配置等价）精确匹配 |
| 简单填空 | `blank` | 标准答案 + `answer_aliases_json` **精确**匹配；不做包含匹配；无法判定 → `pending_review` |

---

## 4. 训练参数

- 难度：基础 / 提高 / 挑战（1/2/3）
- 题量：5 / 10 / 20
- 模式：顺序 / 随机
- 题库：默认正式；测试模式仅管理员或 `chem_train_test_grants` 授权用户可见

---

## 5. 训练任务流程

1. 查询可用题量（`GET /chemistry/train/availability`）  
2. 创建会话并**固定题目顺序与快照**（`POST /chemistry/train/sessions`）  
3. 保存作答（`PATCH .../answers`）  
4. 提交统一判题（`POST .../submit`，已完成则幂等返回）  
5. 查看结果 / 历史（全程 `user_id` 隔离）

状态：`in_progress` | `completed` | `cancelled`

---

## 6. 判题规则

- 规则判题，无 AI 自由判分。  
- 填空：仅明确配置的等价答案；模糊表达 → **待复核**（不计入错误）。  
- 正确率 = 正确 / (正确 + 错误)，**排除待复核**。

---

## 7. 审核与训练准入规则（服务端硬规则）

独立表 `chem_train_items`，**不**把 377 条 KB `question` 骨架当正式题。

正式题（`pool=formal`）同时满足：

1. `status=approved` 且 `is_active=1`  
2. `curriculum_ok=1`，`verify_blocked=0`，`ban_default_train=0`  
3. **至少一条** `chem_train_item_links` 关联知识  
4. 每条关联知识：`status=published`，且 review 标记不含 verifyNeeded / excludeDefault / trainLimit 等禁令  

测试题（`pool=test`）：自洽即可，但**创建/查询必须**服务端验证 ADMIN 或授权表；`counts_formal_stats=0`。

创建与抽题均在服务端检查；前端隐藏不算权限。

---

## 8. 测试题隔离方式

| 机制 | 说明 |
|------|------|
| `pool` 字段 | formal / test |
| `chem_train_test_grants` | 非管理员授权 |
| 请求参数 `poolMode=test` | 无权限 → 403，不能靠改参数绕过 |
| `counts_formal_stats` | 测试会话为 false，不进正式统计；本阶段未接积分 |

本阶段种子：**9** 道测试题（标记「【测试题】」），正式 approved 题：**0**。

因此普通正式训练在绝大多数分类会提示：**「该专项暂无已审核的训练题目。」**
