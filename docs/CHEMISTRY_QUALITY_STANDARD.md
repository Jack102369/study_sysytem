# 高一化学知识库 · 统一质量标准

> 适用系统：中国普通高中高一化学专项训练系统  
> 课程依据：《普通高中化学课程标准》；内容主范围为人教版化学**必修第一册**、**必修第二册**  
> 文档性质：**规范与审查口径**（非人工审核结论）  
> 版本日期：2026-10-18  
> 审查层级声明：本仓库中的 AI/脚本检查结果仅可标记为「已通过自动校验」或「已有可信资料支持」，**不得**标记为「已经人工审核」。

## 1. 定位与范围

### 1.1 系统定位

知识库服务于专项训练（方程式、实验现象、物质性质、计算、离子反应、氧化还原、推断、记忆等），不是百科全书。每条知识应能支撑至少一类题型，或作为关联枢纽。

### 1.2 课程范围（纳入）

| 模块 | 必修主册（人教版口径） | 知识库预期 |
|------|------------------------|------------|
| 物质分类、离子反应、氧化还原 | 必修一 | 概念/公式/知识点完整 |
| 钠及其化合物、氯及其化合物 | 必修一 | 物质/反应/实验/知识点 |
| 铁及其化合物、金属材料 | 必修一 | 物质/反应/实验/知识点 |
| 物质的量及相关计算 | 必修一 | 公式+条件+例题口径 |
| 原子结构、元素周期律、化学键 | 必修二 | 概念/元素/知识点 |
| 化学反应与能量、原电池 | 必修二 | 概念/实验/知识点 |
| 化学反应速率与限度 | 必修二 | 概念（计算另标条件） |
| 有机化学基础（甲烷、乙烯、乙醇、乙酸等） | 必修二 | 物质/反应/实验/概念 |
| 化学实验基础、化学与可持续发展 | 必修一/二 | 实验操作与环保认知 |

### 1.3 超纲处理（必须标记）

下列内容**可以收录**，但必须在 `reviewNote` / 正文标明「选择性必修 / 了解 / 超纲」之一，且默认**不进入**未标注的必修训练题池：

- 选择性必修（化学反应原理、物质结构与性质、有机化学基础加深）内容
- 大学普通化学内容（轨道杂化定量、复杂配位、热力学严格推导等）
- 仅“了解”的元素化合物细节（如铬酸盐深度氧化还原）

未标记而写入必修默认字段 → 审查结论为 **疑似超纲**。

## 2. 十条硬性质量准则

1. **科学规范**：定义、原理符合中学化学通行表述；不得似是而非。  
2. **方程式准确**：原子守恒、电荷守恒；离子方程式拆分规则正确。  
3. **反应条件明确**：温度、催化剂、浓度（稀/浓）、光照、通电等影响产物时必须写清；禁止把特殊条件写成“任意条件均可”。  
4. **实验现象准确**：颜色、沉淀、气体、热量、状态变化与教材及可靠实验事实一致。  
5. **基础概念准确**：电解质/非电解质、氧化剂/氧化产物、单质/纯净物等边界清晰。  
6. **计算公式准确**：表达式、单位、变量含义正确。  
7. **符号与电荷准确**：元素符号大小写、化合价、离子电荷（如 Fe²⁺、Hg₂²⁺）。  
8. **范围可控**：超纲内容必须标记；不得 silently 混入。  
9. **结论可判定**：禁止模棱两可；多答案时写适用条件。  
10. **条件化表述**：存在多种合理答案/产物时，必须说明适用条件（例：钠与氧气常温→Na₂O，加热燃烧→Na₂O₂）。

## 3. 分类型字段最低要求

### 3.1 元素（element）

| 字段 | 要求 |
|------|------|
| 名称/符号/原子序数 | 必须正确 |
| 相对原子质量 | 与所用教材或约定表一致；出计算题前需人工对齐 |
| 周期/族 | 主族用 IA–VIIA / 0；过渡元素按课本 |
| 常见化合价 | 列高一常见价；缺关键常见价→需要修改 |
| 离子符号 | 变价/特殊离子（Hg₂²⁺）不得误导 |
| 电子排布 | 可用高中规则；过渡金属完整排布若写入须标「高中以价态为主」 |

### 3.2 物质（substance）

名称、化学式、分类、颜色、状态、溶解性、关键化学性质、保存/安全（危险品必填）。  
不适用字段可空，**禁止编造**。

### 3.3 反应（reaction）

| 字段 | 要求 |
|------|------|
| canonicalEquation / equation | 配平正确 |
| conditions | 影响产物或能否发生时必填 |
| phenomenon | 支撑现象题时必填且准确 |
| oxidant / reductant / ox_product / re_product | 氧化还原反应必填且**不得对调** |
| species | 反应物/生成物角色与计量一致 |

### 3.4 实验（experiment）

目的、原理、试剂、步骤要点、现象、结论、注意事项；危险实验必须 `isHazardous` + 禁止家用说明。

### 3.5 概念 / 知识点 / 公式

- 概念：定义 + 判断方法或适用条件 + 常见错误  
- 知识点：核心原理 + 典型例子；易错点建议填写  
- 公式：**表达式 + 单位 + 适用条件** 三者缺一不可（计算专项）

## 4. 审查结论四级（逐条唯一）

| 结论 | 含义 | 可否进入自动组卷（建议） |
|------|------|---------------------------|
| **通过** | 自动审查未见明确科学性错误，且范围/条件基本可接受 | 可进入待人工审核队列 |
| **需要修改** | 存在明确错误、关键条件缺失或定义不完整 | 否 |
| **需要人工核实** | 数值来源、教材口径、边界表述存疑 | 否（或仅人工题） |
| **疑似超纲** | 超出必修默认范围且未标记 | 否（除非改标超纲后） |

> **通过 ≠ 已经人工审核。**

## 5. 问题严重度（P0–P3）

| 级别 | 定义 | 示例 |
|------|------|------|
| **P0** | 明确化学事实错误 | 质量数写成“≈”；氧化产物与还原产物对调；方程式配平错误 |
| **P1** | 缺少重要反应条件或关键限定 | 标况未写清；稀释式未排除反应；单质定义缺“纯净物” |
| **P2** | 高一必修核心知识遗漏（清单/覆盖缺口） | 缺 Fe(OH)₂、合金材料专条 |
| **P3** | 表述、格式、关联或完整性优化 | 专项标签挂错；记忆表缺个别离子 |

## 6. 审核状态标签（强制区分）

系统或文档中描述数据可信度时，**只能**使用以下标签之一，且不得混用：

| 标签 | 含义 |
|------|------|
| 已通过自动校验 | 脚本/格式/编码检查通过 |
| 已有可信资料支持 | 可对照课标、教材或公认事实支撑（仍非人审盖章） |
| 需要人工审核 | 待学科教师或授权审核人处理 |
| 已经人工审核 | **仅**真实人工完成审核后可写 |

禁止：将 AI 检查写作「已审核通过」「人工已确认」。

## 7. 训练适用性门槛

| 训练方向 | 最低数据门槛 |
|----------|----------------|
| 方程式书写/配平 | 正确方程式 + 必要条件 |
| 实验现象 | 准确现象字段；危险实验有安全说明 |
| 物质性质 | 关键化学性质/颜色状态不自相矛盾 |
| 化学计算 | 公式含单位与适用条件；过量/标况等边界写清 |
| 离子反应 | 拆分规则与共存条件完整 |
| 氧化还原 | 氧化剂/还原剂/产物判断一致，不得对调 |
| 物质推断 | 颜色、气体、沉淀、转化链可关联 |
| 基础记忆 | 价态/离子/颜色表与必修高频一致 |

不满足门槛的条目：可保留在库中供人工完善，但应在质量报告中标注「不宜直接自动命题」。

## 8. 钠等活泼金属的条件化范例（强制）

| 场景 | 正确条件化表述 |
|------|----------------|
| 钠与氧气 | 常温表面→Na₂O；加热燃烧→Na₂O₂（淡黄色火焰等按教材） |
| 过氧化钠 | 与水、与 CO₂ 分条写清产物与氧气生成 |
| Fe(OH)₂ | 空气中：白色→灰绿→红褐（氧化） |
| 铝两性 | 与酸、与强碱分条；氧化膜影响需说明 |
| 浓硫酸/硝酸 | 稀/浓、加热与否决定产物，禁止笼统一句 |
