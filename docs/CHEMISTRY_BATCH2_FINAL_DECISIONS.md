| 项 | 内容 |
|----|------|
| 知识编码 | `el.O` |
| 拟修改字段 | **`common_valences`（仅此字段；提案未改其他字段）** |
| 当前数据库内容 | `common_valences = "-2"` |
| 建议修改后 | `common_valences = "-2,-1（过氧化物中）"` |
| 修改原因 | 仅列 −2 不完整；必修钠及其化合物涉及 **Na₂O₂**，其中氧为 −1 |

| 优先级 | **优先处理（化学事实不完整，易导致错误训练结论）** |
| 是否仅表述优化 | **否**——属于常见化合价信息缺失 |
| 可能影响的关联 | 后续/已有钠体系：`sub.Na2O2`（清单）、过氧化钠相关反应与知识点；`concept.valence_rules`（过氧化物例外）；价态记忆类题目。不改关联表结构，但组卷时若仍按“氧只有 −2”会冲突 |
| 建议操作 | 确认后仅更新 `common_valences`；可在 `review_note` 注明「过氧化物例外」 |
| 仍然存在的疑问 | 「−1」是否写在元素常见价主字段，还是放到备注/适用条件——**需要人工确认**呈现方式（事实本身不存疑） |
