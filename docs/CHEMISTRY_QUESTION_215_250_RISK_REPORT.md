### 2. 来源知识与关联

- 关联：`knowledge` id=58，名称「**溶液浓度综合**」
- 原文要点：`c=n/V`，**V 为溶液体积（L）**；易错：「V用溶剂体积」
- 知识关联本身（指向浓度知识点）**正确**
- **专项/分类错误**：内容属化学计算/溶液浓度，却挂在离子反应·电解质下

### 3. 问题类型与风险

| 项 | 结论 |
|----|------|
| 问题类型 | 易错短句当题干 → **题干残缺/歧义** |
| 科学性 | 答案「错误」与知识一致（V 不应取溶剂体积） |
| 答案唯一性 | 题干补全后可唯一；当前学生可能无法理解在问什么 |
| 状态建议 | **FIXABLE**（优先修题干+调专项）；暂不修则 **BLOCK_RECOMMENDED** |

### 4. 候选修复方案（待确认后写库）

**建议新题干：**

> 【AI试运行】配制溶液时，物质的量浓度公式 \(c=n/V\) 中的 \(V\) 用溶剂体积。判断正误。

**答案：** 保持 `错误`

**建议解析：**

```
【正确答案】错误
【为什么正确】物质的量浓度 c=n/V 中，V 表示溶液体积（单位 L），不是溶剂体积。只加水稀释时溶质的物质的量 n 不变，可用 c1V1=c2V2，此处 V 同样指溶液体积。
【易错点】把溶液体积与溶剂体积混用；把质量分数的分母（溶液质量）与物质的量浓度的分母（溶液体积）混淆。
```

**分类调整建议：**

| 字段 | 当前 | 建议 |
|------|------|------|
| 一级专项 | ion 离子反应 | **calculation 化学计算** |
| 二级分类 | electrolyte 电解质判断 | **amount 物质的量**（或溶液浓度相关已有分类，以库内实有 code 为准） |
| 知识关联 | kp 溶液浓度综合 | **保持**（正确） |

考查目标修复后仍为：浓度公式中 V 的含义，与来源一致。

### 2. 来源知识要点

- 卤族单质氧化性大致：F₂>Cl₂>Br₂>I₂  
- 卤化氢稳定性大致：HF>HCl>HBr>HI  
- 易错标签：递变顺序记反；含氧酸深度勿当默认核心  

**不得**臆测为原子半径等其它周期性规律。

### 3. 分类与关联

| 项 | 评估 |
|----|------|
| 知识关联 | 指向卤族比较，**正确** |
| 专项 memory/rules | 可接受（规律记忆）；若强调「性质比较」也可归 **periodic**，非必须 |
| 题干 | 「递变顺序记反」无对象、无方向 → **严重残缺** |

### 4. 状态建议

**FIXABLE**（补全为明确错误命题）；否则 **BLOCK_RECOMMENDED**。  
另：来源带 `kb_pending`，修复后仍建议 **NEEDS_SOURCE_VERIFICATION** 关注人审。

### 5. 候选修复方案

**建议新题干（氧化性记反，与来源一致）：**

> 【AI试运行】下列说法正确：卤族单质的氧化性顺序为 I₂>Br₂>Cl₂>F₂。判断正误。

**答案：** 保持 `错误`

**建议解析：**

```
【正确答案】错误
【为什么正确】卤族单质氧化性大致按 F2>Cl2>Br2>I2 递变（以课本为准）。题干写成 I2>Br2>Cl2>F2，属于把递变顺序记反，因此错误。
【易错点】把卤族氧化性顺序记反；或把卤化氢稳定性顺序与单质氧化性顺序混记。
```

**分类：** 可维持 `memory/rules`；可选建议改为 `periodic` 下合适二级（须库内存在对应 code）。**知识关联保持。**
