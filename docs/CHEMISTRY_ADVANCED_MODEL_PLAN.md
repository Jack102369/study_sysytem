## 2. 提高与挑战难度标准

| | 提高（raise） | 挑战（challenge） |
|--|---------------|-------------------|
| 分析 | 约 2～3 个有效步骤 | 多步关联，需选策略 |
| 知识 | ≈2 个关联点 | ≥3 或跨专项组合 |
| 禁止 | 仅改数字/选项序冒充新题 | 冗长题干、超纲、假难度 |
| 标记 | 不得把单步识别题标 raise | 不得只改 `difficulty=3` |

解析建议七段：知识点 → 突破口 → 条件 → 步骤 → 方法总结 → 易错 → 同类识别特征。

## 5. 优先 6 专项模型要点

（细节见 `models_catalog.json`）

1. **计算**：量关系、计量、过量、浓度稀释、Vm、守恒、数据表；（混合物 HOLD）  
2. **氧化还原**：标价识别、氧化剂/产物、电子数、守恒配平思想、产物辨析；（陌生信息 HOLD；连续反应 NEEDS_ENGINE）  
3. **离子**：离子式正误、共存、少量过量、现象结合、电解质；（反应先后 HOLD）  
4. **实验**：操作、现象结论、装置、步骤、误差；（方案评价 NEEDS_ENGINE）  
5. **推断**：现象、转化、多条件、元素、流程；（陌生信息 HOLD）  
6. **综合**：计算+氧化还原、实验+性质、离子+实验、推断+类型、数据文字、策略  

变式要求：改**已知条件 / 求解目标 / 推理路径 / 实验情境 / 知识组合 / 突破口**；禁止仅改数字、物名、选项序当作高价值新题。

---

## 6. 科学性与超纲控制

1. 知识边界：高一必修；选必标 HOLD 或风险说明。  
2. 反应/产物：优先已核实 KB 关系；有机氧化还原勿机械套价。  
3. 答案唯一或完整等价集；条件充分。  
4. 生成：优先本地规则；AI 仅辅助，**不得**标人工审核通过。  
5. 判题：本阶段样例以 single/judge 为主；开放计算/方程式书写等先补引擎。

## 7. 第一批 500 题扩充方案（不入库）

配额（合计 500；约 **350 提高 + 150 挑战**）：

| 专项 | 题量 |
|------|------|
| 化学计算 | 100 |
| 氧化还原 | 90 |
| 离子反应 | 70 |
| 化学实验 | 70 |
| 化学推断 | 80 |
| 化学综合 | 90 |

### 生产顺序（建议）

1. **只使用** `priorityBatch1 ∩ READY`（32 个模型）小样：每模型 3～5 题人工验收。  
2. 按配额扩量：计算 → 氧化还原 → 离子 → 实验 → 推断 → 综合。  
3. 挑战题优先来自已带 challenge 样例的 READY 模型（过量、稀释、多条件推断、误差、综合等）。  
4. `NEEDS_ENGINE`：待 numeric / 更强生成校验后再投产。  
5. `HOLD`：科学审查通过前 **0** 入库。  
6. 入库目标池：个人试运行 test + 准入标记；**正式池仍为 0**；≠人工审核。  

去重：同模型须变更条件结构/目标/路径；重复检测规则写在各模型 `dedupRules`。
