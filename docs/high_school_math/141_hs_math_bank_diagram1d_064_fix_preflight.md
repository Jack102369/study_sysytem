## 3. 术语区分（不得默认等价）

| 术语 | 含义（本测高情境） |
|------|-------------------|
| **仰角** | 观测点处，视线与**水平线**向上的夹角 |
| **俯角** | 观测点处，视线与水平线向下的夹角（本题不用） |
| **顶角** | 通常指三角形某一**顶点处的内角**；若指塔顶 \(T\)，则为 ∠OTB（视线与塔身） |
| **直角三角形内角** | ∠O、∠B、∠T；本题模型取 ∠B=90°（塔铅直、地面水平） |

在 Rt△OBT（∠B=90°）中：若仰角 ∠TOB = \(α\)，则塔顶内角 ∠OTB = \(90^\circ-α\)。  
故 **\(α=30^\circ\) 时顶角≠30°**（顶角应为 60°）。二者**不可默认等同**。

## 4. 数学独立推导（不照抄原解析）

### 4.1 修订后拟采用的模型（与现答案一致）

设定（教材常见测高）：

- \(B\)：塔底；\(T\)：塔顶；塔 \(BT\) **铅直**；地面过 \(B\) **水平**。  
- \(O\)：观测点，在地面上，\(OB = 40\,\mathrm{m}\)（**水平距离**）。  
- **仰角** \(\angle TOB = 30^\circ\)（视线 \(OT\) 与水平线 \(OB\) 的夹角）。  
- 求塔高 \(h = BT\)。

则 Rt△OBT 中：

\[
\tan 30^\circ = \frac{h}{40} \implies h = 40 \cdot \frac{\sqrt{3}}{3} = \frac{40\sqrt{3}}{3}\,\mathrm{m}.
\]

**条件充分**：水平距离 + 仰角 + 铅直塔/水平地 → 唯一确定 \(h\)。  
**与现 standardAnswer / rubric 一致**。

### 4.2 若坚持字面「顶角 \(30^\circ\)」

若「顶角」= ∠OTB = \(30^\circ\)，则仰角 = \(60^\circ\)，

\[
h = 40\tan 60^\circ = 40\sqrt{3}\,\mathrm{m},
\]

与现答案 \(\dfrac{40\sqrt{3}}{3}\) **矛盾**。  
故当前 approved 答案只能在「30°=仰角」解读下成立；题干用词错误/歧义，**应改题干而非改答案**（在维持考点不变前提下）。

### 4.3 核对清单

| # | 问题 | 结论 |

| 1 | 40m 是什么 | 观测点到塔底的**水平距离** \(OB\) |

| 3 | \(h\) 是哪段 | 塔高 \(BT\) |
| 4 | 条件是否充分 | 在「仰角」解读下充分；在「顶角=∠T」解读下可得另一答案，与库内答案冲突 |
