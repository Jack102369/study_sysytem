## 1. 阶段划分（调整说明）

用户建议的 A–F 基本采纳；将「参数化出题」明确移出 P1-0。

| 阶段 | 名称 | 说明 |
|------|------|------|
| **P1-0A** | 教材小节种子 + DB 增量 | migrate + categories 小节 + KP/关联表 |
| **P1-0B** | 知识点管理 API/前端 | 管理端 KP CRUD |

| **P1-0F** | 审核与真实训练验收 | 学生抽题无测试题；回归化学 |

## 2. 各阶段明细

### P1-0A

- **开发**：仅迁移 SQL + init 回写设计；Entity 映射在编码任务。  
- **DB**：见 13；执行需人工确认。  
- **API/前端**：无（或只读校验脚本）。  
- **测试**：schema-audit 扩展。  
- **验收**：十章小节存在；default 仍在；旧会话可读。  
- **影响**：无业务行为变化直至 B/C。

### P1-0B

- **范围**：admin KP API + KnowledgeAdmin 页 + Settings 菜单。  
- **DB**：无新变更（用 A 的表）。  
- **验收**：ADMIN CRUD；USER 403。  
- **影响**：不改训练。

### P1-0C

- **范围**：train-items 关联 KP；createSession 写快照列。  
- **验收**：改 KP 后旧 completed 快照 codes 不变；判题结果不变。  
- **影响**：P0 训练仍可用；无 KP 的题可训。

### P1-0D

- **范围**：导入、自动结构校验、测试前缀拒批。  
- **验收**：导入仅 draft；错误报告完整。  
- **影响**：不改化学。

### P1-0E

- **范围**：第一章题包（文件/导入）；**不** auto-approve。  
- **验收**：人工抽检 ≥10 题答案正确；正式池 >0 且无 E2E code。  
- **影响**：学生该章可训。

### P1-0F

- **范围**：端到端：选小节→训练→提交→历史；回归 chem 计数/菜单。  
- **验收**：见下总验收；双 USER/并发若环境允许复跑。  
- **影响**：无破坏 P0 学情口径。

## 4. 总验收标准（P1-0 Done）

1. 人教 A 版必修一/二小节可浏览。  
2. 知识点可管理并挂题。  
3. 第一章有足够 approved formal 题。  
4. 学生训练不再出现 `HS_MATH_P0_E2E_TEST`。  
5. 历史会话仍可查看；判题结果未重写。  
6. 学情 accuracy 定义未改。  
7. 审核状态机未绕过。  
8. chem / 错题本 / 小学数学包无改。  
9. 迁移可重复执行（幂等）。  
10. 为后续错题本/每日巩固预留（session_kind、wrong 表仍属后续 migrate）。
