## 3. 知识点编码规范

格式：

```
{bookShort}.{chapterNo}.{sectionNo}.{kpSeq}
```

例：

- `rja.1.1.01` 集合的含义与元素  
- `rja.1.3.02` 交集运算  
- `rjb.6.2.01` 向量加法  

规则：

1. `code` 全局唯一、稳定，**改名不改 code**。  
2. `kpSeq` 两位起步，同小节内排序。  
3. 跨小节综合 KP 可用 `rja.1.x.99` 或挂在 `default` 下的 `rja.1.0.xx`（推荐后者仅用于章综合）。  
4. 选择性必修预留：`rja-sel1.*` 等，P1-0 **不建表数据**。

## 5. 层级关系（推荐）

```
教材版本(rja2019)
  └─ 册(book_code)
       └─ 章 hs_math_specialties
            └─ 小节 hs_math_categories（含 default）
                 └─ 知识点 hs_math_knowledge_points
                      └─ 训练题 hs_math_train_items（多对多）
```

**章 ≠ 知识点**；**小节 ≠ 知识点**。

前置依赖：另表 `hs_math_kp_prerequisites`（`kp_id → requires_kp_id`），P1-0A 可先空表或仅第一章少量边。

---

## 6. 最小知识内容（学生可读）

P1-0 知识点实体只存：

- code / name / specialty_id / category_id  
- summary（短定义，≤500 字，可含 `$...$`）  
- sort_order / is_active  

**不建**化学式八类 KB 分表。  
公式/定理/例题/常见错误：P1 后续用 `hs_math_kp_contents`（type 枚举）扩展，**不在 P1-0 强建**。

不存用户掌握度。
