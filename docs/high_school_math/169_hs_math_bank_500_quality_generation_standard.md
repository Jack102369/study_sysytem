# 高一数学 · 每批 500 候选质量生成门禁（第四批经验）

> 适用：后续每批离线 500 候选（含第五批及以后）  
> 来源：GLOBAL-4A / QUALITY-REBUILD / FINAL-QUALITY-CLOSURE  
> **本文件不授权生成第五批**，仅规范。

独立性：任何作者侧流程均标记  
`INDEPENDENT_REVIEW_NOT_FULLY_ESTABLISHED`  
同族审核 **不得** 冒充独立数学终审。

---

## 1. 先设计考查，再写题干

1. 先确定：知识点（合法 KP）、认知目标、解法结构、题型、目标难度。  
2. 再写条件与设问。  
3. 禁止先堆题干再倒推考点。

## 2. 压轴题先有真实难点

压轴（difficulty=3）必须先写下：

- 核心思维难点（具体，禁止空话）  
- 完整解题路线  
- 为何超出提高题  

禁止仅用「综合性较强 / 思维要求高 / 多知识点」交差。  
禁止靠加大计算量或机械步骤冒充压轴。

## 3. 每 20 题即时验收

按 5×100 推进；组内每 20 题为一个 QC 单元：  
数学正确性 → 难度真实性 → 去重 → rubric/插图 → 落盘。  
不得攒到 500 再首次质检。

## 4. 禁止无意义去重填充句

禁止：辅助参数、区分参数、不改变选项、数据指纹、题号装饰句等。  
去重应靠 **考查结构差异**，不是加废话。

## 5. 禁止机械换数字扩题

数字替换、同解法模板、同条件结构换皮 → 一律视为低价值同构，应淘汰或重设计。

## 6. 低价值候选直接淘汰

三轮修复仍无训练价值 → **替换**，不润色凑数。

## 7. 数学验证证据与题目同步

每题证据至少含：核心推导、答案依据、难度依据、rubric 结论、去重结论、插图结论。  
与题干同一次落盘；禁止事后空写「已核对」。

## 8. Application 与 rubric 同步

125 道过程题：满分、分项、总和、不重复计分、不奖励抄题干、替代解法可得分。  
程序校验只是必要非充分条件。

## 9. 插图在最终题干确定后制作

REQUIRED 随最终题干重判；数量可变；必须 100% 配齐、数学正确、不泄题。  
禁止先画图再凑题。

## 10. 自动校验 ≠ 教学质量 PASS

结构/配额/格式 ok 只是门槛。  
教学质量以数学复核与教学价值审查为准。

## 11. 独立终审隔离

作者自检、同助手族系 review **不等于**独立终审。  
入库前应安排独立主体抽检。

---

## 建议门禁清单（进入导入预检前）

- [ ] 留白句 = 0  
- [ ] exact 去重 vs 正式题+既有候选+批内 = 0  
- [ ] 低价值同构清零或每条有 ACCEPTABLE_VARIANT 教学增量说明  
- [ ] 全部 d3 有实质难点档案  
- [ ] application rubric 全数人工可复核  
- [ ] REQUIRED 图与最终题干一致且 SHA 齐全  
- [ ] 证据 JSON 500 条完整  
- [ ] 状态仅允许：READY_FOR_IMPORT_PREFLIGHT / QUALITY_PARTIAL / BLOCKED  

---

## 12. 压轴质量前置门禁（GLOBAL-4D 经验 · 第五至第九批强制）

下列条款来自第四批弱压轴返工，**生成前就必须满足**，禁止靠改难度档案或放宽校验“刷 PASS”。

### 12.1 禁止虚标压轴

- `difficulty=3` 必须对应真实需要的推理链；禁止“简单题 + hardProfile 七字段”凑数。  
- hardProfile 七字段 + `contentSha256` 为**必要非充分**条件；字段齐全 ≠ 难度达标。  
- 禁止通过删弱题启发式规则、降低 WEAK 门禁或只改 `difficulty` 标签获得 PASS。

### 12.2 弱压轴必须逐题分类（禁止批量放行）

对启发式/抽查命中的压轴，逐题标为：

| 类 | 含义 | 最低证据 |
|----|------|----------|
| A_TRUE_D3 | 真压轴误报 | **具体推导** + 说明启发式为何误报；禁止批量认定 A |
| B_REBUILD_REQUIRED | 整题重做 | 新考查目标→标准解→题干 |
| C_DOWNGRADE_REQUIRED | 降为 d1/d2 并同章补真 d3 | 配额守恒证明 |
| D_MATH_ISSUE | 数学错误 | 错误点 + 修复或替换 |

每条绑定当时 `contentSha256`；改题后旧证据/旧 PASS **全部作废**。

### 12.3 设计顺序：目标 → 解 → 干

压轴生成顺序固定为：

1. 考查目标（合法 KP + 认知目标）  
2. 真实核心难点（可检验，非空话）  
3. 完整标准解（含易错与检验）  
4. 再写题干/选项  

禁止：先写简单题再机械加条件；禁止仅换数字扩题（digit-strip 同构一律淘汰）。

### 12.4 禁止模板壳题

禁止下列“壳”冒充压轴（多选/单选/判断/应用均适用）：

- 「关于“××”，下列正确的是」+ 万能选项（正确表述/说反/漏定义域/特例冒充恒真）  
- 解析短于实质推导、或仅复读 hardProfile 空话  
- 应用题仅有「见解析」而无可复核中间量  

壳题一律按 B 类整题替换。

### 12.5 多族结构去重

同章同题型压轴须准备 **≥ 组内需求数** 的结构族；仅改参数导致 `normStem` 撞车视为未完成。  
去重靠考查结构差异，禁止辅助参数/题号装饰句。

### 12.6 改题后全量重验

任何改干/改答/改解析/改 KP·method/改 rubric/改配图后：

- 答案与解析一致性重验  
- KP/method 映射重验  
- application rubric 和校验  
- 语义/结构去重重跑  
- REQUIRED 图与 SHA 随最终题干更新  
- hardProfile.`contentSha256` 重绑  
- 旧批次 `IMPORT_PREFLIGHT_PASS` **失效**，须复跑完整预检  

### 12.7 配额诚实

500 / 175·200·125 / 题型与章节配额必须守恒，但 **禁止虚标 d3 凑配额**。  
若降级，必须同章同题型补真压轴，并在报告中给出置换表。

### 12.8 独立终审隔离（不变）

作者侧预检 PASS ≠ 独立数学终审。  
一律保留：`INDEPENDENT_REVIEW_NOT_FULLY_ESTABLISHED`。  
未达质量如实报 `IMPORT_PREFLIGHT_PARTIAL` / `BLOCKED`，不得降门禁。
