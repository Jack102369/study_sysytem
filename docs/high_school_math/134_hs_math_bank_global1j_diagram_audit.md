## 2. CAND-G1B-093 独立数学核验

### 2.1 题目与标准答案（库内原文）

- 题干：正方体 \(ABCD-A_1B_1C_1D_1\) 中，证明 \(BD_1\perp\) 平面 \(A_1C_1D\)。  
- 标准答案 / rubric：证 \(BD_1\perp A_1C_1\)、\(BD_1\perp A_1D\)，再得线面垂直。  
- 解析：数量积为 0；两相交直线在平面内；线面垂直判定。

### 2.2 标准坐标

\[
\begin{align*}
A&=(0,0,0),\; B=(1,0,0),\; C=(1,1,0),\; D=(0,1,0)\\
A_1&=(0,0,1),\; B_1=(1,0,1),\; C_1=(1,1,1),\; D_1=(0,1,1)
\end{align*}
\]

### 2.3 向量与点积

| 向量 | 计算 | 结果 |
|------|------|------|
| \(\overrightarrow{BD_1}\) | \(D_1-B\) | \((-1,1,1)\) |
| \(\overrightarrow{A_1C_1}\) | \(C_1-A_1\) | \((1,1,0)\) |
| \(\overrightarrow{A_1D}\) | \(D-A_1\) | \((0,1,-1)\) |
| \(\overrightarrow{BD_1}\cdot\overrightarrow{A_1C_1}\) | \(-1+1+0\) | **0** |
| \(\overrightarrow{BD_1}\cdot\overrightarrow{A_1D}\) | \(0+1-1\) | **0** |

### 2.4 平面内性与相交（线面垂直判定前提）

| 检查 | 结果 |
|------|------|
| \(\overrightarrow{A_1C_1}\) 是否在平面 \(A_1C_1D\) | **是**（连结平面内两点 \(A_1,C_1\)） |
| \(\overrightarrow{A_1D}\) 是否在平面 \(A_1C_1D\) | **是**（连结 \(A_1,D\)） |
| 两直线是否相交 | **是**（交于 \(A_1\)） |
| 两直线是否不共线（可作平面内两相交直线） | **是**（方向 \((1,1,0)\) 与 \((0,1,-1)\) 不平行） |
| 证明是否偷换「平行线/异面线」为相交线 | **否** |
| 标准答案 / rubric / 解析是否一致 | **是**（两条线垂 → 线面垂） |

**结论：命题与评分逻辑数学正确。缺的是示意图，不是改结论。**  
→ 不构成 `CRITICAL_FOUND`。

用户所见「管理员页无正方体图」与审计一致：当前**无图可显**。

## 4. 图形协议与前端现状（只读）

### 4.1 数据层

`hs_math_train_items`（`db/init.sql` / Entity）字段含 `stem` / `options_json` / `answer_payload_json` / `analysis` 等，**无**：

- `stem_image_*` / `diagram_*` / `figure_*` / `media_*` / `attachments`

`SHOW COLUMNS`：image-like 列 = **[]**。

现有「image」相关能力是 **学生作答手写拍照**（`MathApplicationInput` + `hs-math-auth-image`），**不是题干插图**。

### 4.2 渲染层

| 位置 | 行为 |
|------|------|
| 学生训练 / 结果 | `MathStem` → `renderMathHtml`（KaTeX `$...$`） |
| HTML 安全 | 对非公式段 **escape** `<` `>` → 即使把 `<img>` 塞进 stem **也不会显示图片** |
| Admin 预览 | 同源文本公式渲染；**无**题干图预览组件 |
| SVG/PNG 私有存储鉴权 | **无**题干图协议；作答图另有鉴权通道，不可挪用冒充题干图 |
| 移动端缩放 | 仅公式横向 `overflow-x: auto`；无插图 pinch/zoom 方案 |

**结论：当前平台不支持正式题干配图；补图前需单独授权的协议/存储/渲染阶段，本审计不开发。**
