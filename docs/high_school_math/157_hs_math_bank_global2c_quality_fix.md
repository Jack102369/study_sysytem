**旧：** \(\log_3 81=\) → 4（与 **G1B-040 完全相同**）

- 题干：求 \(\log_4 32\) 的值（可先化为同底指数或使用换底公式）。  
- 答案：\(\dfrac{5}{2}\)

- method：`equiv_transform` + `defn`  
- difficulty：**3**（同底/换底求非整数，较定义直读更有训练价值）  
- 推导：\(4^x=32\Rightarrow 2^{2x}=2^5\Rightarrow x=5/2\)；或 \(\dfrac{\log_2 32}{\log_2 4}=\dfrac{5}{2}\)

**去重：**

| 对照 | 结论 |
|------|------|
| G1B-040 \(\log_3 81=\) | 不同底、不同真数、不同技能点 |
| G1B-036 \(\log_2 32=\) | 同真数 32 但底为 2，答案 5；本题需换底/同底化到 \(5/2\) |
| 本批其它题 | 无 `log_4 32` / 同 dedupNote |
