## CAND-G3A-059

- 小节：6.1 平面向量的概念
- KP：`rjb.6.1.01` 向量概念
- 题型/难度：single / 1
- method：defn
- 配图：NOT_NEEDED
- 来源：original

**题干**

下列物理量中，属于标量的是

**选项**

- A. 速度
- B. 加速度
- C. 功
- D. 动量

**答案**

C

**解析**

向量既有大小又有方向；标量只有大小。速度、加速度、动量均有方向，是向量；功只有大小（正负表示做功或克服阻力），是标量。故选 C。

**作者自检**：功为标量；速加动量为向量

**题干**

设 $\vec a\ne\vec 0$，下列说法正确的有（多选）

**选项**

- A. $|-\vec a|=|\vec a|$
- B. $-\vec a$ 与 $\vec a$ 方向相反

下列向量组可以作为平面内一组基底的有（多选）

## CAND-G3A-068

- 小节：6.4 平面向量的应用
- KP：`rjb.6.4.04` 几何证明
- 题型/难度：application / 3
- method：equiv_transform + substitution
- 配图：REQUIRED
- 来源：original

**题干**

如图，在平行四边形 $ABCD$ 中，用向量方法证明：对角线 $AC$ 与 $BD$ 互相平分。

**答案**

设对角线交点为 $O$，则 $\overrightarrow{AO}=\overrightarrow{OC}$ 且 $\overrightarrow{BO}=\overrightarrow{OD}$（或证得交点为两对角线中点）。

**解析**

设 $\overrightarrow{AB}=\vec a$，$\overrightarrow{AD}=\vec b$。则 $\overrightarrow{AC}=\vec a+\vec b$，$\overrightarrow{BD}=\vec b-\vec a$。对角线中点：取 $AC$ 中点 $M$，则 $\overrightarrow{AM}=\dfrac12(\vec a+\vec b)$；取 $BD$ 中点 $N$，由 $\overrightarrow{AB}+\overrightarrow{BN}=\overrightarrow{AN}$ 得 $\overrightarrow{AN}=\vec a+\dfrac12(\vec b-\vec a)=\dfrac12(\vec a+\vec b)$。故 $M$ 与 $N$ 重合，两对角线互相平分。

**Rubric**（满分 10）

- setup 设基向量 3：合理用邻边表示四边形向量
- mid 中点向量 4：分别写出两对角线中点的位置向量并相等
- conc 结论 3：得出对角线互相平分

**作者自检**：两对角线中点位置向量同为(a+b)/2

## CAND-G3A-072

- 小节：6.4 平面向量的应用
- KP：`rjb.6.4.01` 向量应用
- 题型/难度：application / 3
- method：equiv_transform + num_shape
- 配图：RECOMMENDED
- 来源：original

**题干**

在 $\triangle ABC$ 中，$\angle C=90^\circ$，$M$ 为斜边 $AB$ 的中点。用向量方法证明：$|\overrightarrow{CM}|=\dfrac12|\overrightarrow{AB}|$。

**答案**

$|\overrightarrow{CM}|=\dfrac12|\overrightarrow{AB}|$

**解析**

设 $\overrightarrow{CA}=\vec a$，$\overrightarrow{CB}=\vec b$，则 $\vec a\cdot\vec b=0$。$\overrightarrow{AB}=\vec b-\vec a$，$M$ 为中点：$\overrightarrow{CM}=\dfrac12(\vec a+\vec b)$。于是 $|\overrightarrow{CM}|^2=\dfrac14(|\vec a|^2+|\vec b|^2)=\dfrac14|\overrightarrow{AB}|^2$，故 $|\overrightarrow{CM}|=\dfrac12|\overrightarrow{AB}|$。

**Rubric**（满分 10）

- setup 设向量 3：以直角顶点为原点设两直角边向量并写垂直
- mid 中线模 5：推出 $|CM|^2=\frac14|AB|^2$
- conc 结论 2：得中线为斜边一半

**作者自检**：a·b=0 ⇒ |a+b|^2=|a|^2+|b|^2=|b-a|^2
