## 4. 分题理由（精要）

### 4.1 建议维持

- **0001–0003,0005–0007,0010,0011,0014–0016,0019**：定义/定义域/标准模型/一步求值或图象识记 → 基础。
- **0004,0008,0009,0012,0013,0021**：多选、易错定义域、零函数、绝对值、对称点陷阱 → 提高。
- **0022**：奇函数「正半轴递增 ⇒ 负半轴递增」需变量替换与不等式变号，**非直接**；章节综合压轴可立，高考压轴深度不足 → 保持 3 + BORDERLINE。
- **0023**：偶函数单调方向迁移 + `f(|x|)=f(x)` + 「偶不蕴含单调」 → 同理保持 3 + BORDERLINE。

### 4.2 建议降档

- **0017 (2→1)**：`f(-1)+f(-2)`，两次奇规则再加，无新方法。
- **0018 (2→1)**：所求仅 `f(-4)=f(4)`；`f(x)=ax^2+b`、`f(0)=1` 为干扰。
- **0020 (2→1)**：`(a,b)→(-a,-b)` 直接对应。
- **0024 (3→2)**：命题「奇函数一定单调」为假；反例 `x^3-x` 即可，无长推理链。
- **0025 (3→1)**：`f(-1)=f(1)=1+1=2`，两步直接；原 3 虚高。

### 4.3 未建议升级

本批无「标了 1/2 但实际需要非直接综合推理」的题；**零升级**。
