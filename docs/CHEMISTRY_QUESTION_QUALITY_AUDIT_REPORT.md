## 13. 审查局限性（必读）

1. 本审查为 **规则 + 来源字段交叉 + 二审状态继承**，不是逐题人工化学教授审定。  
2. PASS **≠** 人工审核通过。  
3. 无法在无实验/教材对照下证明全部现象/用途表述绝对正确；字段复述题的正确性绑定知识库质量。  
4. 语义重复仅覆盖规范化题干与同模板角度；更细的同义改写可能漏检。  
5. 启发式曾短暂误伤 `NO2+H2O` 歧化反应，已修正后重跑；类似边界仍可能存在。
