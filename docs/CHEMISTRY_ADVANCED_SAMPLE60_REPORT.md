## 4. 核验结果

### 4.1 科学正确性与复算

- 对含明确数值的样题做了独立复算（计算专项及综合/氧化还原中的计量题）。
- **无**「声明答案 vs 独立复算」冲突。
- 规则：**确定性复算优先**；DeepSeek 若与复算冲突，记录冲突但不覆盖复算结论（本批无此类冲突）。

### 4.2 答案唯一性

- `optionAudit` 与选项审查未发现「多正确答案」未处理题。
- DeepSeek：`uniqueAnswer=false` **0** 题；`ambiguity=true` **0** 题。
- 生产过程中曾发现并当场改写的风险点（已消除）：
  - 离子正误题双正确选项 → 已改写错误系数选项；
  - 「电荷不守恒」设问与选项事实不符 → 已改为左+2/右+3；
  - 碳/硫燃烧仅靠石灰水区分不足 → 已加品红条件。

### 4.3 查重

- 对照个人开放前备份题库 stems（594 行快照）+ 批内两两相似度。
- 近重阈值 0.85：**批内 0 / 库内 0**。
- 说明：新样题为提高/挑战多步或条件筛选，与现有偏基础/单步题库差异较大；**不等于**永久免重，入库前仍应再跑查重。

### 4.4 机械重复

- 同模型可多题，但题干条件、设问角度不同（如碳酸盐酸足量/少量成对题）。
- 未发现「只改数字/只改物质名」的空壳重复链。
- 风险提示：氧化还原识别类有若干「标价→判断」同构，能力标签相近，后续扩量需模板参数化拉开。

## 8. 质量观察（诚实）

**优点**

- 全单选 + 完整 `optionAudit`，可对接错题中心/薄弱诊断设计；
- 计算与氧化还原计量题可复算；
- 离子分步（足量/少量酸）成对体现「条件控制」而非单步识别；
- DeepSeek 全覆盖且与复算无冲突。

**不足 / 风险**

- 挑战题真实难度仍不均匀：已拦截 3 道「假挑战」；其余 PASS 挑战题中，部分实验操作题仍偏规范记忆，后续应提高「误差链/除杂顺序/多条件」占比；
- 部分提高题（尤其氧化还原识别、实验规范）接近「基础+」，DeepSeek 未全部降级，扩量时需更严的难度标尺；
- `optionAudit.possibleWrongThinking` 仅供诊断假设，**禁止**直接当作学生真实错因写进学情结论。
